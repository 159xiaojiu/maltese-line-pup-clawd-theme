处理建议（给其他 AI）
--------------------
1. 保留黑色描边 #000000，只去掉外围纯黑背景
2. 动图须保持原始帧数，不要压成单帧
3. 避免重压缩导致线条虚化
4. 透明色不要用纯黑（会与描边冲突），建议色键 #010101
